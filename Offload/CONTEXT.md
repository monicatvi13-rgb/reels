## Проект

**Offload** — iOS-приложение (SwiftUI, iOS 17+), голосовой помощник-«Джарвис» для русскоязычных.

- Репозиторий: GitHub `monicatvi13-rgb/reels`, ветка `claude/ecstatic-ritchie-vv8pl9`, папка `Offload/`.
- Подробное описание структуры — в `Offload/README.md`.
- Bundle id: `com.neurosistema.offload`, виджет — `com.neurosistema.offload.widget`.

### Что уже работает

1. Голос или текст → нейросеть раскладывает мысли по полочкам (Сегодня / По датам / Идеи / Быт), списки в SwiftData.
2. Две нейросети на выбор: **GigaChat** (по умолчанию, бесплатно для физлиц, работает в РФ) и Claude (по желанию). Каждый пользователь подключает свой ключ, приложение бесплатное.
3. GigaChat работает: сертификаты Минцифры встроены в код (`RussianCertificates.swift`) + исключение ATS для sberbank.ru в `Info.plist`.
4. Вкладка «Спросить»: разговор голосом, команды (добавить, отметить, перенести, удалить), память разговора, имя и характер помощника.
5. Утренняя сводка и напоминания (уведомления), Календарь / «Напоминания».
6. Siri, кнопка «Действие», виджет — написаны, но **не проверены** (нужен iPhone).
7. Голос ответов — Apple (AVSpeechSynthesizer) по фразам с паузами и выбором темпа. Мне он не нравится: «почти такой же», неживой.
8. **Студия голоса** (Настройки ⚙️ → «Студия голоса»): запись фраз для обучения нейросети моему голосу.

## Где мы сейчас: свой нейросетевой голос

**Цель:** помощник говорит **моим голосом**, живо, как человек. Это «визитная карточка» приложения.

**Решения, которые уже приняты:**
- Yandex SpeechKit отвергнут: слишком дорого при большом числе пользователей. Платные облачные голоса не подходят.
- Голос должен работать **прямо на iPhone, бесплатно и без интернета**.
- Важно, сколько это стоит. Главный вариант — обучение на моём Mac (бесплатно, по оценке 2–4 дня, оценка не проверена). Запасной — аренда GPU (по грубой оценке 1–10 тыс. ₽).

**Студия голоса (как устроена):**
- Код: `Offload/Offload/VoiceStudio/` — `StudioRecorder.swift`, `VoiceStudioView.swift`, `sentences.txt` (425 фраз).
- Каждая фраза → WAV 44,1 кГц, моно, 16 бит → `Documents/VoiceDataset/wavs/offload_0001.wav` и т.д. (внутри песочницы приложения).
- Кнопка «Собрать архив» → `OffloadVoice.zip`: папка `wavs/` + `metadata.csv` в формате LJSpeech: `offload_0001|текст фразы`.
- Управление на Mac: пробел — запись/стоп, стрелки — назад/вперёд.

**Что я только что сделала:** записала уже много фраз (не дочитала, что сначала нужно 3–5 на пробу). На рабочем столе у меня лежит **VoiceDataset** (папка или архив).
