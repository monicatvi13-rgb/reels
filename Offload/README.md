# 🌿 Offload

Приложение для iPhone, которое помогает не держать всё в голове.
Наговори или напиши всё, что крутится в мыслях, хаотично и вперемешку. Claude разложит это по четырём «полочкам»:

| Полочка | Что туда попадает |
|---|---|
| ☀️ **Сегодня** | Срочное и то, что лучше сделать сегодня |
| 📅 **По датам** | Дела и события с конкретным днём или сроком |
| 💡 **Идеи** | Мысли, планы, «на подумать» |
| 🧺 **Быт** | Покупки и домашние дела |

**Статус:** этап 1 — базовый каркас.
Требования: iOS 17+, Xcode 16+.

## Как устроен проект

```
Offload/
├── Offload.xcodeproj        ← открывать двойным кликом в Xcode
└── Offload/
    ├── OffloadApp.swift     ← точка входа, подключает хранилище данных
    ├── Models/
    │   └── Models.swift     ← что храним: «слив мыслей» и пункты списков
    ├── Services/
    │   ├── SpeechRecognizer.swift  ← голос → текст (на устройстве)
    │   ├── ClaudeService.swift     ← отправка текста в Claude и разбор ответа
    │   └── KeychainStore.swift     ← безопасное хранение API-ключа
    ├── Views/
    │   ├── RootView.swift       ← две вкладки внизу
    │   ├── DumpView.swift       ← экран «Выгрузить»
    │   ├── ListsView.swift      ← экран «Мои списки»
    │   ├── EditItemView.swift   ← правка и добавление пункта
    │   ├── SettingsView.swift   ← ввод API-ключа
    │   └── Theme.swift          ← цвета и стиль
    └── Assets.xcassets      ← иконка и акцентный цвет
```

## Как запустить на своём iPhone

1. Открой `Offload.xcodeproj` в Xcode на Mac.
2. Слева нажми на синюю иконку **Offload** → вкладка **Signing & Capabilities** → в поле **Team** выбери свой Apple ID. Если его там нет, нажми **Add Account** и войди. Хватит бесплатного аккаунта.
3. Подключи iPhone кабелем и выбери его вверху окна Xcode вместо симулятора.
4. Нажми ▶️ (или `Cmd + R`).
5. Первый раз iPhone может не пустить приложение. Тогда открой на телефоне **Настройки → Основные → VPN и управление устройством**, выбери свой Apple ID и нажми «Доверять».
6. Если iPhone попросит включить **Режим разработчика**: **Настройки → Конфиденциальность и безопасность → Режим разработчика**.

## API-ключ Claude

Ключ **не зашит в код**. Добавить его можно двумя способами:

- **В самом приложении** (удобнее): шестерёнка на главном экране → вставить ключ → «Сохранить». Ключ хранится в Keychain — защищённом хранилище iPhone.
- **Через Xcode** (для разработки): Product → Scheme → Edit Scheme → Run → Arguments → Environment Variables → добавить `ANTHROPIC_API_KEY`. Работает только при запуске из Xcode.

Ключ создаётся на [console.anthropic.com](https://console.anthropic.com/settings/keys). Запросы платные: деньги списываются с баланса аккаунта.

> ⚠️ Хранить ключ в приложении нормально для личного пользования и тестов. Для публикации в App Store нужен свой небольшой сервер-посредник, чтобы ключ не лежал в приложении у каждого пользователя. Это отдельный этап.
