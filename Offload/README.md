# 🌿 Offload

Голосовой помощник для iPhone, который забирает мысли из головы.
Наговори всё, что крутится в голове, вперемешку. Нейросеть разложит это по четырём «полочкам»:

| Полочка | Что туда попадает |
|---|---|
| ☀️ **Сегодня** | Срочное и то, что лучше сделать сегодня |
| 📅 **По датам** | Дела и события с конкретным днём или сроком |
| 💡 **Идеи** | Мысли, планы, «на подумать» |
| 🧺 **Быт** | Покупки и домашние дела |

**Статус:** этап 3 — разговор голосом, уведомления, утренняя сводка и Календарь.
Требования: iOS 17+, Xcode 16+.

| Где взять ключ | [developers.sber.ru/studio](https://developers.sber.ru/studio) | [console.anthropic.com](https://console.anthropic.com/settings/keys) |

Голос, списки и всё остальное работают одинаково с обеими нейросетями.

## ⚠️ Один раз перед сборкой: сертификат для GigaChat

Серверы GigaChat используют сертификат Минцифры, которому iPhone по умолчанию не доверяет. Без него GigaChat не подключится (Claude работает и без него).

> Устанавливать сертификаты в «Связку ключей» на Mac **не нужно**. Файлы просто кладутся в папку проекта.

1. Скачай сертификаты Минцифры с официального сайта Госуслуг: [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt). Нужны два файла:
   - **корневой** — Russian Trusted Root CA (обязателен);
   - **промежуточный** — Russian Trusted Sub CA (желательно).
2. Переименуй их в **`russian_trusted_root_ca.cer`** и **`russian_trusted_sub_ca.cer`** (расширение `.crt` тоже подойдёт).
3. Положи оба файла в папку `Offload/Offload/`, рядом с `OffloadApp.swift`. Xcode подхватит их сам.
4. Собери приложение заново (▶️).

Сертификат вкладывается в приложение один раз. Пользователям ничего устанавливать не нужно.

## Как устроен проект

```
Offload/
├── Offload.xcodeproj
├── Info.plist                        ← разрешения для Календаря и «Напоминаний»
└── Offload/
    ├── OffloadApp.swift
    ├── Models/Models.swift           ← «слив мыслей» и пункты списков (с датой и временем)
    ├── Services/
    │   ├── AI/
    │   │   ├── AIProvider.swift      ← выбор нейросети и её ключ
    │   │   ├── LLMClient.swift       ← общий «разъём» для любой нейросети + ошибки
    │   │   ├── GigaChatClient.swift  ← подключение к GigaChat (токен, сертификат)
    │   │   ├── ClaudeClient.swift    ← подключение к Claude
    │   │   ├── ThoughtSorter.swift   ← разбор мыслей по полочкам
    │   │   └── Assistant.swift       ← собеседник: ответы на вопросы о делах
    │   ├── Briefing.swift            ← фразы о делах и ответы без нейросети
    │   ├── VoiceService.swift        ← озвучка ответов голосом iPhone
    │   ├── NotificationScheduler.swift ← утренняя сводка и напоминания

    │   ├── AppSync.swift             ← обновляет уведомления и Календарь после изменений
    │   ├── AppSettings.swift         ← настройки
    │   ├── SpeechRecognizer.swift    ← голос → текст (на устройстве)
    │   └── KeychainStore.swift       ← безопасное хранение ключей
    ├── Views/
    │   ├── RootView.swift            ← три вкладки
    │   ├── DumpView.swift            ← «Выгрузить»
    │   ├── AssistantView.swift       ← «Спросить» — разговор голосом
    │   ├── ListsView.swift           ← «Списки»
    │   ├── EditItemView.swift        ← правка пункта (дата и время)
    │   ├── GuideView.swift           ← «Как подключить нейросеть»

```

## Как запустить

1. Открой `Offload.xcodeproj` в Xcode.
2. Вверху выбери симулятор iPhone или подключённый телефон и нажми ▶️.
3. Для запуска на своём iPhone: синяя иконка **Offload** слева → **Signing & Capabilities** → в поле **Team** выбери свой Apple ID.
4. Первый запуск на iPhone: **Настройки → Основные → VPN и управление устройством** → «Доверять». Если попросит, включи **Режим разработчика** в разделе «Конфиденциальность и безопасность».

Для разработки ключи можно передать и через Xcode: Product → Scheme → Edit Scheme → Run → Environment Variables → `GIGACHAT_AUTH_KEY` или `ANTHROPIC_API_KEY`.
